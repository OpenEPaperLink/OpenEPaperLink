## What is this ?

This is a Claude authored script that creates a markdown file summarizing 
the contents of resources/tagtypes.

For example see [defined tagtypes](https://github.com/OpenEPaperLink/OpenEPaperLink/wiki/tagtype-notes#defined-tagtypes-as-of-10312026) in the Wiki.

## Usage

Usage: python3 summarize_tagtypes.py ../../resources/tagtypes
